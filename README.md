# IoT Lab Management System

## Project Overview
The IoT Lab Management System is a web-based
application designed to manage IoT laboratory
devices and equipment.

## Features
- Device inventory management
- Device availability tracking
- Issue and return management
- Student borrowing records
- Device information management

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
