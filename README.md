## Key Features

- Manage IoT laboratory devices through a centralized digital system.
- View device details and check equipment availability.
- Maintain records of available and issued devices.
- Track equipment issuing and returning activities.
- Store student borrowing information.
- Record issue dates for better tracking.
- Simplify laboratory inventory management and reduce manual record-keeping.

## System Workflow

1. Open the IoT Lab Management System.
2. Browse the list of available laboratory devices.
3. Select the required IoT device.
4. Enter the student's borrowing details.
5. Record the device issue date.
6. Update the device availability status.
7. Monitor issued devices and their return status.
8. Update the inventory when a device is returned.

## Project Objective

The main objective of this project is to simplify IoT laboratory management through a digital platform. It provides an organized way to maintain device records, monitor equipment availability, manage student borrowing activities, and track issued and returned devices. The system helps reduce manual paperwork, improve inventory management, and make laboratory operations more efficient.
